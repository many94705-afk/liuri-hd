# 流日人类图

📱 **打开网页**：<https://many94705-afk.github.io/liuri-hd/>（手机浏览器打开后「添加到主屏幕」即可像 App 一样使用）

手机 App 式的人类图工具，底部五个标签：

- **人体图**：本命图（个性蓝 / 设计粉）、两侧星体闸门爻线，以及类型、权威、人生角色、轮回交叉、定义的通道。
- **解读**：任选日期和时间，看流日接通了你的哪些通道——每条从几点到几点、还剩多久、由哪颗星体接通，以及接下来 24 小时的预告。
- **月历**：每月每天中午接通的通道；连续 3 天以上的连成色带；只靠月亮接通的不列入。
- **土星回归**：流年土星回到出生土星位置的精确日期（约 29、58、87 岁；逆行时一次回归有 3 个精确点）与倒计时，以及流年土星经过出生土星闸门的时间段。
- **我的**：保存多个人的档案，在顶部切换。

全部计算在你自己的设备上完成：不需要服务器、不上传出生信息、打开过一次后断网也能用。档案只保存在本机浏览器里。星历使用 Swiss Ephemeris（内置 Moshier 星历，WebAssembly 版）。

## 手机上使用（iPhone / 安卓）

1. 用手机浏览器打开上面的网址。
2. iPhone：Safari 点「分享 → 添加到主屏幕」；安卓：浏览器菜单里选「添加到主屏幕」。
3. 第一次打开会进入「我的」，填写名字、出生日期、时间和时区（中国大陆出生填 +08:00，会自动处理 1986—1991 年夏令时；其他地区填例如 Asia/Tokyo）。

## 文件

- `index.html`：页面；`localapi.js`：在浏览器里完成全部计算。
- `engine.js`：闸门爻线、设计时刻（太阳往前 88°）、接通通道及起止时间；`saturn.js`：土星回归。
- `bodygraph.js`、`hdsummary.js`、`hdcontent.js`、`hdcrosses.js`、`channels.js`、`monthlayout.js`：人体图绘制、推算与说明文字、月历排布。
- `vendor/`：Swiss Ephemeris 的 WebAssembly 版本（来自 `@swisseph/browser` 1.4.0）。
- `sw.js`、`manifest.json`：离线缓存与添加到主屏幕。
